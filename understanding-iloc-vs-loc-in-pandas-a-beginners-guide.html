Understanding iloc vs loc in Pandas: A Beginner's Guide

Aakash Khandelwal May 23, 2025 pandas

Introduction

Pandas is a powerhouse for data manipulation in Python, and two of its most commonly used methods for selecting data from a DataFrame are loc and iloc. If you’re new to Pandas or transitioning from beginner to intermediate, understanding the difference between these two methods is essential for efficient data handling. In this post, we’ll break down loc and iloc, explore their differences, and provide practical examples to help you master data selection in Pandas.

What Are loc and iloc?

Both loc and iloc are used to select rows and columns from a Pandas DataFrame, but they differ in how they reference data:

  • loc: A label-based indexing method. It uses row and column labels (e.g., column names or index names) to select data.
  • iloc: An integer-based indexing method. It uses integer positions (0-based indices) to select data, regardless of the labels.

Think of loc as working with the “names” of rows and columns, while iloc works with their “positions.”

Key Differences

Here’s a quick comparison to set the stage:

Featurelociloc
Indexing TypeLabel-basedInteger-based
Selection MethodUses row/column labelsUses integer positions (0-based)
Inclusive/ExclusiveInclusive of end labelExclusive of end index
Use CaseWhen working with meaningful labelsWhen order/position matters

Let’s dive into examples to see these methods in action.

Setting Up a Sample DataFrame

To illustrate loc and iloc, let’s create a simple DataFrame:

import pandas as pd

data = {
    'Name': ['Alice', 'Bob', 'Charlie', 'David'],
    'Age': [25, 30, 35, 40],
    'City': ['New York', 'London', 'Paris', 'Tokyo']
}
df = pd.DataFrame(data, index=['a', 'b', 'c', 'd'])
print(df)

Output:

       Name  Age     City
a    Alice   25  New York
b      Bob   30   London
c  Charlie   35    Paris
d    David   40    Tokyo

This DataFrame has labeled rows (a, b, c, d) and columns (Name, Age, City). Let’s use loc and iloc to select data.

loc: Label-Based Indexing

The loc method allows you to select rows and columns by their labels. You can use it to select:

  • A single row or column.
  • Multiple rows or columns.
  • A range of rows or columns.
  • Specific rows and columns together.

Example 1: Selecting a Single Row

To select the row with index b:

print(df.loc['b'])

Output:

Name       Bob
Age         30
City    London
Name: b, dtype: object

Here, loc['b'] returns the row labeled b as a Series.

Example 2: Selecting a Specific Cell

To get Charlie’s age (row c, column Age):

print(df.loc['c', 'Age'])

Output:

35

Example 3: Selecting a Range of Rows

You can select a range of rows using a slice. Note that loc is inclusive of the end label:

print(df.loc['a':'c'])

Output:

       Name  Age     City
a    Alice   25  New York
b      Bob   30   London
c  Charlie   35    Paris

Example 4: Selecting Specific Columns

To select the Name and City columns for rows b and d:

print(df.loc[['b', 'd'], ['Name', 'City']])

Output:

    Name     City
b    Bob   London
d  David    Tokyo

iloc: Integer-Based Indexing

The iloc method uses integer positions to select data, similar to how you’d index a Python list. It’s useful when you don’t care about labels or when the DataFrame has numeric indices.

Example 1: Selecting a Single Row

To select the second row (index position 1):

print(df.iloc[1])

Output:

Name       Bob
Age         30
City    London
Name: b, dtype: object

Example 2: Selecting a Specific Cell

To get the value in the third row, second column (Charlie’s age):

print(df.iloc[2, 1])

Output:

35

Example 3: Selecting a Range of Rows

Unlike loc, iloc is exclusive of the end index:

print(df.iloc[0:3])

Output:

       Name  Age     City
a    Alice   25  New York
b      Bob   30   London
c  Charlie   35    Paris

Notice that 0:3 selects rows 0, 1, and 2, but not 3.

Example 4: Selecting Specific Columns

To select the first and third columns for the first two rows:

print(df.iloc[0:2, [0, 2]])

Output:

    Name     City
a  Alice  New York
b    Bob   London

When to Use loc vs. iloc

  • Use loc when:

    • Your DataFrame has meaningful labels (e.g., dates, categories).
    • You want to select data by name, like a dictionary.
    • You need inclusive range slicing.

  • Use iloc when:

    • You’re working with numeric positions (e.g., first 10 rows).
    • Labels are irrelevant or unavailable.
    • You’re iterating programmatically over a DataFrame.

Common Pitfalls

  • Using loc with non-existent labels: If you try df.loc['z'], you’ll get a KeyError unless z exists in the index.
  • Using iloc with out-of-bounds indices: df.iloc[10] will raise an IndexError if the DataFrame has fewer than 11 rows.
  • Confusing inclusive/exclusive slicing: Remember that loc includes the end label, while iloc excludes the end index.

Performance Considerations

For small DataFrames, the performance difference between loc and iloc is negligible. However, iloc can be slightly faster for large datasets because integer-based indexing avoids label lookups. Always test with your specific data to confirm.

Conclusion

Mastering loc and iloc is a key step in becoming proficient with Pandas. Use loc for label-based selection when your data has meaningful row or column names, and iloc for position-based selection when you’re working with indices. By understanding their differences and practicing with examples, you’ll be able to navigate DataFrames with confidence.
