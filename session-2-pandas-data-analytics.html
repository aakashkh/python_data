A Practical Guide to Pandas Logical Operations, Filtering, Indexing, and More

Today, we’re diving into some of the most powerful tools in pandas for data manipulation: logical operations, filtering, negation, indexing with loc and iloc, replacing values, mapping values, and, if time allows, lambda functions. Whether you’re cleaning data, selecting specific subsets, or transforming values, these techniques are essential for any data analyst or scientist. Let’s break it down step by step, with hands-on examples to make it stick.

Setting Up Our Environment

We’ll use a sample DataFrame to demonstrate these concepts. The code below creates a dataset of students with names, ages, grades, and subjects, which we’ll manipulate throughout this session.

import pandas as pd
import numpy as np

# Create a sample DataFrame
data = {
    'Name': ['Alice', 'Bob', 'Charlie', 'David', 'Emma'],
    'Age': [20, 22, 19, 21, 20],
    'Grade': [85, 90, 78, 92, 88],
    'Subject': ['Math', 'Science', 'Math', 'History', 'Science']
}
df = pd.DataFrame(data)
print("Original DataFrame:")
print(df)

# Logical Operations
print("\nLogical Operations: Students who are 20 or older and study Math")
condition = (df['Age'] >= 20) & (df['Subject'] == 'Math')
print(df[condition])

# Filtering and Negation
print("\nFiltering: Students with Grade >= 85")
print(df[df['Grade'] >= 85])
print("\nNegation: Students NOT studying Science")
print(df[~ (df['Subject'] == 'Science')])

# Indexing with loc and iloc
print("\nUsing loc: Select Name and Grade for Age >= 20")
print(df.loc[df['Age'] >= 20, ['Name', 'Grade']])
print("\nUsing iloc: Select first 3 rows and first 2 columns")
print(df.iloc[:3, :2])

# Replace and Map
print("\nUsing replace: Change 'Math' to 'Mathematics'")
df_replaced = df.replace({'Subject': {'Math': 'Mathematics'}})
print(df_replaced)
print("\nUsing map: Assign pass/fail based on Grade")
df['Pass/Fail'] = df['Grade'].map(lambda x: 'Pass' if x >= 80 else 'Fail')
print(df)

# Lambda Functions (optional)
print("\nUsing lambda with apply: Increase Age by 1")
df['Age_Plus_One'] = df['Age'].apply(lambda x: x + 1)
print(df)

1. Logical Operations: Combining Conditions

Pandas allows you to combine conditions using logical operators:

  • AND (&): Both conditions must be true.
  • OR (|): At least one condition must be true.
  • NOT (~): Inverts the condition.

For example, to find students who are 20 or older and study Math, we use &:

condition = (df['Age'] >= 20) & (df['Subject'] == 'Math')
df[condition]

This returns rows where both conditions are satisfied. Parentheses are crucial to ensure proper operator precedence.

2. Filtering and Negation: Selecting and Excluding Data

Filtering in pandas involves selecting rows based on conditions. For instance, to get students with grades of 85 or higher:

df[df['Grade'] >= 85]

Negation (~) is useful for excluding specific conditions. To find students not studying Science:

df[~ (df['Subject'] == 'Science')]

This excludes rows where the subject is Science, returning all other subjects.

3. Indexing with loc and iloc: Precise Data Selection

Pandas provides two powerful indexing methods:

  • loc: Label-based indexing. Use column names and row labels.
  • iloc: Integer-based indexing. Use row and column indices.

For example, to select the Name and Grade columns for students aged 20 or older:

df.loc[df['Age'] >= 20, ['Name', 'Grade']]

To select the first three rows and first two columns by index:

df.iloc[:3, :2]

Key Difference: Use loc when working with labels (e.g., column names), and iloc when working with numerical positions.

4. replace and map: Transforming Data

  • replace: Replaces specific values in a DataFrame or Series. For example, to change “Math” to “Mathematics”:
df.replace({'Subject': {'Math': 'Mathematics'}})
  • map: Applies a function or mapping to a Series. To assign “Pass” or “Fail” based on grades:
df['Pass/Fail'] = df['Grade'].map(lambda x: 'Pass' if x >= 80 else 'Fail')

Note: map works on a single Series, while replace can operate on the entire DataFrame.

5. Lambda Functions: Custom Transformations (Optional)

Lambda functions are anonymous functions defined on the fly. They’re perfect for quick transformations in pandas. For example, to increase every student’s age by 1:

df['Age_Plus_One'] = df['Age'].apply(lambda x: x + 1)

The apply method runs the lambda function on each element. Lambda functions are versatile but can be slower for large datasets, so use them wisely.

  2. Use loc to select the Name and Subject columns for these students.
  3. Replace “Science” with “Sci” in the Subject column.

Key Takeaways

  • Logical operations (&, |, ~) let you combine conditions for filtering.
  • Filtering selects rows based on conditions; negation excludes specific cases.
  • loc and iloc provide flexible ways to index DataFrames.
  • replace and map are go-to methods for transforming values.
  • Lambda functions offer custom flexibility but should be used thoughtfully.
