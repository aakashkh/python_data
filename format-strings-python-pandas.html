Mastering Python's Format Strings (with Pandas Examples)

Aakash Khandelwal May 19, 2025 python

Let’s break down the d type code and explore some other useful format specifiers within format strings.

In the format string '{0}_m{1:02d}_d{2:02d}'.format(2025, 1, 5), the parts within the curly braces {} are replacement fields. Let’s focus on {1:02d} and {2:02d}:

  • {1} and {2}: These refer to the index of the argument passed to the .format() method. {0} corresponds to 2025, {1} to 1, and {2} to 5.

  • :: This colon introduces the format specification. It tells Python how to format the value of the corresponding argument.

  • 02d: This is the format specifier itself. Let’s dissect it:

    • d: This is the type code for decimal integer. It ensures that the argument (which should be an integer) is formatted as a standard base-10 integer.
    • 02: This is the width and fill part.
      • 2: This specifies that the output should have a minimum width of 2 characters.
      • 0: This specifies the fill character. If the integer has fewer than 2 digits, it will be padded with leading zeros to reach the specified width.

So, in the example:

  • {1:02d} formats the second argument (which is 1) as a decimal integer with a minimum width of 2, padding with a leading zero if necessary. This results in "01".
  • {2:02d} formats the third argument (which is 5) similarly, resulting in "05".

Therefore, the entire format string produces: "2025_m01_d05".

Now, let’s explore some other common and useful type codes and format specifiers you might encounter, especially in the context of Pandas when dealing with different data types:

Common Type Codes:

  • s: String. Formats the argument as a string (this is often the default if no type is specified).

    "Name: {0:s}".format("Alice")  # Output: "Name: Alice"

  • d: Decimal integer. Formats the argument as a base-10 integer (as we saw).

    "Age: {0:d}".format(30)      # Output: "Age: 30"

  • f: Fixed-point number. Formats the argument as a decimal number with a fixed number of digits after the decimal point (default is 6).

    "Price: {0:.2f}".format(12.345) # Output: "Price: 12.35" (rounded to 2 decimal places)
"Value: {0:8.3f}".format(100.1) # Output: " Value: 100.100" (width 8, 3 decimal places)

  • e: Exponent notation. Formats the argument in scientific notation.

    "Scientific: {0:.2e}".format(0.000123) # Output: "Scientific: 1.23e-04"

  • %: Percentage. Multiplies the argument by 100 and displays it with a percent sign.

    "Probability: {0:.1%}".format(0.755) # Output: "Probability: 75.5%"

  • b: Binary. Formats the argument as a binary number.

    "Binary: {0:b}".format(10)      # Output: "Binary: 1010"

  • o: Octal. Formats the argument as an octal number.

    "Octal: {0:o}".format(10)       # Output: "Octal: 12"

  • x: Hexadecimal (lowercase). Formats the argument as a hexadecimal number (using lowercase letters).

    "Hex (lower): {0:x}".format(255)  # Output: "Hex (lower): ff"

  • X: Hexadecimal (uppercase). Formats the argument as a hexadecimal number (using uppercase letters).

    "Hex (upper): {0:X}".format(255)  # Output: "Hex (upper): FF"

Other Useful Format Specifiers (within the :):

  • Width: You can specify the minimum width of the output field (e.g., {0:10s} will make the string at least 10 characters wide, padding with spaces if necessary).

  • Alignment: You can control the alignment of the output within the specified width:

    • <: Left-aligned (default for strings)
    • >: Right-aligned (default for numbers)
    • ^: Centered
    "Left: '{0:<10s}'".format("hello")   # Output: "Left: 'hello     '"
"Right: '{0:>10s}'".format("hello")  # Output: "Right: '     hello'"
"Center: '{0:^10s}'".format("hello") # Output: "Center: '  hello   '"
"Right-align number: '{0:>5d}'".format(12) # Output: "Right-align number: '   12'"

  • Fill character: You can use a specific character for padding (other than space), placed before the alignment character.

    "Zero-padded: '{0:0>5d}'".format(12)  # Output: "Zero-padded: '00012'"
"Star-centered: '{0:*^10s}'".format("hi") # Output: "Star-centered: '****hi****'"

  • Sign: For numbers, you can control the display of the sign:

    • +: Always display the sign (+ for positive, - for negative)
    • : Display a space for positive numbers and a minus sign for negative numbers (default)
    • -: Only display the minus sign for negative numbers (default)
    "Positive with sign: '{0:+d}'".format(5)   # Output: "Positive with sign: '+5'"
"Negative with sign: '{0:+d}'".format(-5)  # Output: "Negative with sign: '-5'"
"Space for positive: '{0: d}'".format(5)   # Output: "Space for positive: ' 5'"
"Space for negative: '{0: d}'".format(-5)  # Output: "Space for negative: '-5'"

  • Thousands separator: You can use a comma (,) or an underscore (_) to add a thousands separator for numeric types.

    "With comma: {0:,d}".format(1234567)   # Output: "With comma: 1,234,567"
"With underscore: {0:_f}".format(12345.678) # Output: "With underscore: 12_345.678000"

In the context of Pandas:

You’ll often use these formatting options when:

  • Converting Pandas Series or DataFrame columns to strings with specific formats. For example, when creating reports or exporting data.
  • Formatting date and time information. Pandas uses its own sophisticated date and time handling, but when you need to represent dates as strings, format strings are essential. You’ll often see format codes like %Y (year with century), %m (month as a zero-padded decimal number), %d (day of the month as a zero-padded decimal number), %H (hour (24-hour clock)), %M (minute), %S (second), etc. These are used with methods like .strftime() on datetime objects within Pandas.
